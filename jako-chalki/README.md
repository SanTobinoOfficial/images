# jako-chalki

Kopia strony [Sklep Chałki](https://jakubserafin.github.io/jako-chalki/) z następującymi modyfikacjami:

- Po kliknięciu jajka 10 razy odpala się pułapka wideo (autoplay, pełny ekran)
- Przycisk "Zamknij" ucieka od kursora i nie działa
- Blokada wyjścia ze strony (beforeunload + History API)
- Blokada F5 / Ctrl+R / Ctrl+W

Obrazy produktów ładowane z oryginalnej strony GitHub Pages.
