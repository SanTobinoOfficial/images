# jako-chalki

Kopia [Sklep Chałki](https://jakubserafin.github.io/jako-chalki/) z pułapką wideo.

## Jak dodać swoj wideo

Dodaj plik o nazwie **`trap.mp4`** do tego folderu. Zostanie automatycznie odtworzony po wykluciu jajka.

## Co robi strona

- Po kliknięciu **Jajo Chałki → Dodaj do koszyka** pojawia się mini-gra (10 kliknięć)
- Po wykluciu odpala się pełnoekranowe wideo z `trap.mp4`
- **Nie można wyjść ze strony:** beforeunload, blokada historii (co 500ms), ciągłe przejmowanie focusu, blokada F5/F12/Ctrl+R/Ctrl+W/Ctrl+Shift+I
- Przycisk „Zamknij” ucieka spod kursora
